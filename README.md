# Données publiques de SuiviPublic

Données publiées par [SuiviPublic](https://suivipublic.fr), qui suit de façon neutre et sourcée les textes de loi, les votes, le budget de l'État et les annonces de l'exécutif. Le format est décrit dans la documentation du projet ; chaque montant renvoie à sa source et à son contrôle.

- `meta.json` : référentiels (thèmes, titres de dépense, lignes de recettes).
- `sources.json` : sources citées, avec leur licence.
- `journal.json` : journal éditorial (ajouts, corrections, extractions rejetées).
- `budget/etat-AAAA.json` : budget de l'État (nomenclature, crédits par programme, article d'équilibre, solde prévu).
- `budget/liminaire-AAAA.json` : prévisions de solde et de dette de l'article liminaire des lois de finances.
- `budget/secu-AAAA.json` : objectifs de dépenses par branche et objectif national de dépenses d'assurance maladie.
